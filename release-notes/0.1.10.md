FileHub v0.1.10

小版本，主要是修预览的回归。

## 修复
- 图片预览和尺寸判断改成按内容识别，不再看扩展名；PNG 存成 `.jpg` 的文件（Immich 备份里很常见）恢复正常预览
- 无法识别的图片格式提示改成“无法识别图片格式”，不再误报“图片过大 未知尺寸”
- aarch64 版改用 `access(2)`，Termux 上不会再因为 `faccessat2` 被 seccomp 拦截而启动即崩

## 说明
- 0.1.9 的 aarch64 资产当时是热替换的，0.1.10 才是三平台一致的完整版本
- 只用到浏览器端的，直接升级 x86_64 即可；Termux 用户用 0.1.10 的 aarch64 包
- 升级前建议备份 `filehub.db`

FileHub v0.1.10

A small release, mostly fixing a preview regression.

## Fixed
- Image dimensions and the preview gate now detect the content format instead of trusting the extension; PNG payloads named `.jpg` (common in Immich backups) preview normally again
- Unsupported formats now say "Unrecognized image format" instead of the misleading "Image is too large (unknown size)"
- aarch64 builds use `access(2)`; Termux no longer dies at startup when seccomp rejects `faccessat2`

## Notes
- The v0.1.9 aarch64 asset was hot-swapped; v0.1.10 is the first release where all three platforms are consistent
- Browser-only users can just upgrade x86_64; Termux users should use the 0.1.10 aarch64 package
- Back up `filehub.db` before upgrading
