FileHub v0.1.9

This update is a big one. Here are the highlights:

## Security
- Terminal `rm` / `cp` / `mv` can no longer delete or copy the whole storage root by mistake
- Public-share uploads can no longer escape the root through symlinks
- Login failures no longer reveal whether a username exists
- Per-user terminal / ZIP / extraction switches, enforced by the backend
- Tighter permissions for temp files, cache, avatars, and SQLite
- Per-user file-count limit to prevent inode exhaustion

## Terminal
- `help`, `-h` / `--help`
- `zip`, `unzip`, `job` / `jobs`, `roots`
- `ls` now shows size, modified time, cached folder sizes, and totals
- High-risk `rm` still asks for a 4-digit code even with `-y`
- Cross-root copy/move: `cp a.txt @2:/path`
- Minimizable terminal; clicking outside no longer closes it

## Files and search
- Long paths collapse into `…` instead of scrolling
- Search pathbar shows the query, filters, and loaded count
- Long filenames keep only sane short extensions; weird suffixes no longer break the layout
- Double-click uses file type; directories always win
- Dragging a multi-selection now moves every selected item
- Right-click "Create ZIP" and "Extract"
- Blank-area right-click "Directory overview"
- Search results support sorting, list/grid, thumbnails, multi-select, and bulk delete/share

## Video
- AC3 / EAC3 / DTS / TrueHD default audio tracks are detected; audio-only transcode playback is available

## Admin
- Users and external paths have their own page; external paths on top, users below
- Renaming an external path updates assigned user aliases
- More system settings: thumbnails, uploads, extraction, index, jobs, security, symlinks
- Byte fields accept B / KB / MB / GB / TB
- Dangerous settings show warnings and recommended ranges; some say restart required
- Each group has "Restore defaults"
- High-risk security settings are collapsed and need the admin password
- "Restart server" at the bottom
- Audit IPv6 is truncated, full address on hover, click to copy

## Performance
- Independent concurrency for indexing, directory size, thumbnails, ZIP/extract, and video transcode
- File-level parallel copy/move
- Quick scan default changed from 10 to 60 minutes

## Fixes
- Gap between short filenames and their extension
- Audit IPv6 table overflow
- Sidebar not updating after an external path rename
- SSE reconnect/dropped events now resync
- Multi-select drag moving only one file

## Known limits
- Same-root terminal `cp/mv` does not have per-byte live progress yet
- Full TOCTOU hardening is not done
- Multi-instance deployments still use an in-process SSE event bus

Back up `filehub.db` before upgrading. Use the musl package on Linux and replace the exe on Windows.

FileHub v0.1.9

这次更新挺多的，挑重点说：

## 安全
- 终端 `rm` / `cp` / `mv` 不会再误删或复制整个存储根目录
- 公共分享上传不再被符号链接带到 root 外面
- 登录失败不再暴露用户名是否存在
- 新增按用户的终端 / ZIP / 解压开关，后端强制生效
- 临时文件、缓存、头像、SQLite 数据库权限收紧
- 新增每用户文件数量上限，防止 0 字节文件耗尽 inode

## 终端
- 新增 `help`、`-h` / `--help`
- 新增 `zip`、`unzip`、`job` / `jobs`、`roots`
- `ls` 默认显示大小、修改时间和目录大小汇总
- 高危删除即使带 `-y` 也要输入 4 位验证码
- 跨 root 复制/移动：`cp a.txt @2:/path`
- 终端可以最小化，点窗口外面不会直接关掉

## 文件和搜索
- 长路径中间折叠成 `…`，不再横向滚动
- 搜索时 pathbar 直接显示关键词、筛选和已加载数量
- 长文件名只保留正常短后缀，奇怪后缀不会把布局撑坏
- 双击按文件类型打开，目录永远优先
- 多选拖动现在会移动全部选中项
- 右键新增“打包为 ZIP”和“解压”
- 空白处右键新增“目录概览”
- 搜索支持排序、列表/网格、缩略图、多选、批量删除/分享

## 视频
- AC3 / EAC3 / DTS / TrueHD 默认音轨会提示，并提供只转音频的“转码播放”

## 管理页
- 用户与外部链接单独一页，外部路径在上、用户在下
- 外部路径改名会自动同步用户侧别名
- 系统设置补齐缩略图、上传、解压、索引、任务、安全、符号链接等选项
- 字节字段支持 B / KB / MB / GB / TB
- 危险设置有风险提示和建议范围，部分标注“重启生效”
- 每组设置支持“恢复默认”
- 高风险安全设置默认折叠，展开需输入管理员密码
- 底部新增“重启服务器”
- 审计日志 IPv6 省略显示，悬停看完整地址，点击复制

## 性能
- 索引扫描、目录大小、缩略图、ZIP/解压、视频转码都有独立并发
- 复制/移动任务内部支持多文件并行
- quick scan 默认从 10 分钟改成 60 分钟，减少常驻索引

## 修复
- 短文件名和后缀之间的大空白
- 审计日志 IPv6 撑破表格
- 外部路径改名后左栏不更新
- SSE 断线/丢事件后状态不同步，现在会自动 resync
- 多选拖动只移动一个文件

## 已知限制
- 同 root 的 `cp/mv` 还没有逐字节实时进度条
- TOCTOU 全量加固还没做
- 多实例部署时 SSE 事件总线还是进程内的

升级前建议备份 `filehub.db`。Linux 下载 musl 静态包，Windows 下载 exe 覆盖后重启服务。
