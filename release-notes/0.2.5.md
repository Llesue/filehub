# FileHub 0.2.5

0.2.5 makes remote mounts update in near real time and polishes the sidebar, previews and editor.

## Highlights

- Remote mounts keep a WebSocket presence channel, so a dropped peer goes offline immediately and reconnects with jittered backoff.
- Grant, token and capability changes reach the peer within a heartbeat, including token rotation detected from the prefix.
- Health checks run per mount with a 10 second budget, so one dead peer cannot stall a healthy mount.
- Every sidebar group can be drag-reordered inside its own slots, and a root that goes offline keeps its position when it returns.
- Offline remote roots are inert and report through a toast instead of opening a blocking dialog.
- Mobile image preview uses a blurred full-screen backdrop, tap to toggle the chrome, double-tap 150% zoom and pinch zoom anchored under the fingers.
- The share dialog shows a square QR card and copies a ready-to-send message with the link and expiry.
- Markdown preview toggles with `Ctrl/Cmd+Shift+P`, and `Ctrl/Cmd+S` or Save no longer closes the editor.
- EXIF make, model and lens values lose their padding bytes, and exposure and aperture read `1/101 s` and `f/1.6`.
- Search hides and purges index rows whose files disappeared outside FileHub, and scans treat a vanished parent under a reachable root as a deletion.
- Stopping the service closes event streams, terminal and presence sockets, cancels background jobs and waits for their cleanup before the WAL checkpoint.
- The Windows service reports `StopPending` while it drains, so `sc stop` completes instead of hanging.

## Upgrade

No database migrations. Existing data upgrades in place.

# FileHub 0.2.5

0.2.5 让远程挂载的状态接近实时，并打磨了侧栏、预览和编辑器。

## 亮点

- 每个远程挂载保持一条 WebSocket 在线通道，断开立即离线，重连使用带抖动的指数退避。
- 授权、令牌和能力变更在一个心跳内到达对端，心跳里的 token 前缀也能发现令牌轮换。
- 健康检查按挂载独立执行，每个 10 秒预算，一个死挂载不会拖住正常挂载。
- 侧栏每个分组都能拖动排序，只重排自己占用的槽位，目录临时离线再恢复时位置不变。
- 离线远程目录不再可点击，改为右下角 toast 提示，不再弹阻塞对话框。
- 手机图片预览使用模糊全屏背景，单击切换界面元素，双击放大到 150%，双指缩放以手指为锚点。
- 分享弹窗显示正方形二维码卡片，可复制带链接和截止日期的分享文案。
- Markdown 预览用 `Ctrl/⌘+Shift+P` 切换，`Ctrl/⌘+S` 和保存按钮只保存，不关闭编辑器。
- EXIF 制造商、型号和镜头不再带尾部填充字节，曝光和光圈显示为 `1/101 s` 和 `f/1.6`。
- 搜索会过滤并清理在 FileHub 之外消失的索引记录，扫描遇到根可读但父目录消失时按删除处理。
- 停止服务时会关闭事件流、终端和 presence 连接，取消后台任务并等待清理完成后再做 WAL checkpoint。
- Windows 服务在退出期间上报 `StopPending`，`sc stop` 不再挂起。

## 升级

没有数据库迁移，现有数据可直接升级。
