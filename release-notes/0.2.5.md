# FileHub 0.2.5

0.2.5 makes remote mounts report their state in near real time and adds the UI work requested after 0.2.4.

## Remote mounts

- Each mount keeps a WebSocket presence channel. A dropped socket marks it offline immediately; reconnects use exponential backoff with jitter.
- Older peers without the endpoint fall back to the health loop.
- The channel pushes `grant.revoked`, `grant.updated`, `token.revoked`, `token.rotated`, `capabilities.changed`, `owner.changed`, `welcome` and `shutdown`.
- A rotated token is also detected from the token prefix carried by heartbeats, even if the event was lost.
- Health checks run per mount with a 10 second budget, so unreachable peers can no longer starve a healthy mount.
- Disabling inbound sharing, disabling the share feature or disabling a user now blocks federation requests immediately.
- The sidebar shows a toast when a remote directory goes online or offline.

## Sidebar

- Every group can be reordered by dragging: local roots, online remotes and offline remotes.
- Dragging is limited to one group. Only the slots that group already occupies are permuted, so a root that goes offline returns to the same position.
- Offline remote roots are no longer clickable and no longer open a blocking dialog.

## Preview and sharing

- Mobile image previews use a blurred full-screen backdrop with a full-width image.
- Tap toggles the controls; double-tap zooms to 150% and stays in fullscreen.
- Pinch zoom now stays anchored under the fingers.
- The share QR dialog shows a card with the file type, name, square QR code and expiry, and can copy a ready-to-send message with the link.

## Editor and metadata

- Markdown preview toggles with `Ctrl/Cmd+Shift+P`.
- `Ctrl/Cmd+S` and the Save button save without closing the editor.
- EXIF make, model and lens values from Android camera uploads no longer show trailing padding bytes.
- Exposure and aperture are formatted as `1/101 s` and `f/1.6`.

## Shutdown

- Stopping the service closes event streams, terminal and presence sockets, cancels background jobs and waits for their cleanup.
- The Windows service reports `StopPending` while it drains, so `sc stop` completes instead of hanging.

## Upgrade

No database migrations. Existing data upgrades in place.

# FileHub 0.2.5

0.2.5 让远程挂载的状态接近实时，并补上了 0.2.4 之后提出的一批界面改进。

## 远程目录

- 每个挂载保持一条 WebSocket 在线通道，断开立即标记离线；重连使用带抖动的指数退避。
- 旧版本对端没有这个端点时，自动退回健康轮询。
- 通道推送 `grant.revoked`、`grant.updated`、`token.revoked`、`token.rotated`、`capabilities.changed`、`owner.changed`、`welcome` 和 `shutdown`。
- 心跳携带 token 前缀，即使事件丢失也能发现轮换。
- 健康检查改为每个挂载独立任务、10 秒预算，死挂载不再拖住正常挂载。
- 关闭入站共享、关闭共享功能或禁用用户后，联邦请求立即被拒绝。
- 远程目录上线/离线时，侧栏弹出 toast。

## 侧栏

- 每个分组都能拖动排序：本地根、在线远程、离线远程。
- 只允许组内拖动；只重排该组已占用的槽位，目录临时离线再恢复时位置不变。
- 离线远程目录不再可点击，也不再弹阻塞对话框。

## 预览与分享

- 手机图片预览改为模糊全屏背景、图片占满宽度。
- 单击切换界面元素，双击放大到 150% 并保持全屏。
- 双指缩放以手指中点为锚点，不再漂移。
- 分享二维码弹窗显示卡片：文件类型、文件名、正方形二维码和截止日期，可复制带链接的分享文案。

## 编辑器与元数据

- Markdown 预览用 `Ctrl/⌘+Shift+P` 切换。
- `Ctrl/⌘+S` 和保存按钮只保存，不关闭编辑器。
- 安卓拍照上传的 EXIF 制造商、型号、镜头不再带尾部填充字节。
- 曝光和光圈显示为 `1/101 s`、`f/1.6`。

## 退出

- 停止服务时会关闭事件流、终端和 presence 连接，取消后台任务并等待清理完成。
- Windows 服务在退出期间上报 `StopPending`，`sc stop` 不再挂起。

## 升级

没有数据库迁移，现有数据可直接升级。
