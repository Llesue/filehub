# FileHub 0.2.4

0.2.4 fixes remote mount status, share links and dialog behaviour.

## Remote mounts

- A reachable remote no longer shows as offline. A successful health check from the last two minutes is trusted; only stale mounts are probed again, with a 3–8 second budget.
- Health checks run every 20 seconds and push `roots.changed` when a mount comes back or drops, so the sidebar recovers without reloading the page.
- Opening an offline remote root clears the previous root's list and switches the view to read-only: upload, delete, rename and drag-and-drop are disabled.

## Sharing

- Multi-file download from a share works again. Browsers submit repeated `paths` fields and the server now parses them as a list.
- Browser downloads stream through a form endpoint, so a multi-file selection starts right away.
- On phones the share selection bar stacks above the buttons and a blank tap clears the selection.
- The QR dialog shows a 1080×1600 share card with the file type, file name, a square QR code and the expiry date. Download it or copy a ready-to-send link.
- Image previews support two-finger pinch zoom and panning; swipe navigation is unchanged.

## Dialogs

- Dragging a text selection out of the editor or another dialog no longer closes it. The backdrop only closes when the press and the release both happen on the backdrop.

## Upgrade

No database migrations.

Full changelog: https://github.com/Llesue/filehub/compare/v0.2.3...v0.2.4

# FileHub 0.2.4

0.2.4 修复远程挂载状态、分享链接和对话框行为。

## 远程目录

- 能连上的远程目录不再显示离线。两分钟内健康检查成功过就直接信任；只有过期的挂载才重新探测，超时放宽到 3–8 秒。
- 健康检查改为每 20 秒一次，挂载恢复或掉线时推送 `roots.changed`，侧栏不用刷新页面就能更新状态。
- 进入离线的远程根会清空上一个根的列表并切换为只读：上传、删除、重命名和拖放全部禁用。

## 分享

- 分享页多选下载恢复。浏览器提交的是重复的 `paths` 字段，服务端现在按列表解析。
- 浏览器下载改为表单流式触发，多选文件会立刻开始打包。
- 手机上的分享选择栏把数量放到按钮上方，点击空白处取消选择。
- 二维码弹窗直接显示 1080×1600 的分享卡片：文件类型、文件名、正方形二维码和截止日期；可下载图片或复制带提示语的链接。
- 图片预览支持双指捏合缩放和拖动平移；单指左右滑动切换保持不变。

## 对话框

- 从编辑器或其他对话框里拖选文字到外部松开，不再误关闭。只有按下和松开都发生在遮罩上时才关闭。

## 升级

没有数据库迁移。
