# FileHub 0.2.8

0.2.8 adds a first-run setup wizard for Windows, fixes hard-link quota accounting, and makes directory views consistent.

## Highlights

- Double-clicking an unconfigured `filehub.exe` opens a setup wizard: port, listen address, data directory, and whether to install the Windows service, all with defaults.
- The wizard copies the executable to `C:\Program Files\FileHub`, installs and starts the service, adds a firewall rule when listening on `0.0.0.0`, and opens the browser.
- On first start the setup token is written to `<data dir>\setup-token.txt` (readable only by the service account and administrators), copied to the clipboard, and removed after setup.
- `filehub service install --start` installs and starts the service in one step.
- Hard links no longer inflate used space: bytes are counted once per file, while every hard-link path still counts as its own entry. Windows uses file IDs when available.
- Directory listings now default to the tile view sorted by modification time, newest first; view and sort preferences are stored per directory.
- Remote directories that were already offline no longer toast on every page load; real online/offline changes still notify.

## Upgrade

No database migrations. Existing 0.2.7 data upgrades in place. The first usage refresh after upgrading may report a lower `used_bytes` for users with hard links; that is the corrected value.

Full changelog: https://github.com/Llesue/filehub/compare/v0.2.7...v0.2.8

# FileHub 0.2.8

0.2.8 加入 Windows 首次启动向导，修正硬链接配额计量，并统一目录视图行为。

## 亮点

- 双击未配置的 `filehub.exe` 会进入向导：端口、监听地址、数据目录、是否安装 Windows 服务，全部有默认值。
- 向导会把程序复制到 `C:\Program Files\FileHub`，安装并启动服务；监听 `0.0.0.0` 时添加防火墙规则，然后打开浏览器。
- 首次启动时 setup token 写到 `<数据目录>\setup-token.txt`（仅服务账号和管理员可读），复制到剪贴板，完成设置后删除。
- `filehub service install --start` 一条命令完成安装并启动服务。
- 硬链接不再重复计算已用空间：同一文件的字节只算一次，但每个硬链接路径仍作为独立条目计数；Windows 在可用时使用文件 ID。
- 目录列表默认使用平铺视图和修改时间倒序；视图和排序偏好按目录保存。
- 打开页面时已经离线的远程目录不再反复弹提示；运行中真实上线/离线仍会通知。

## 升级

没有数据库迁移，现有 0.2.7 数据可直接升级。升级后第一次重新统计用量时，有硬链接的用户可能会看到 `used_bytes` 下降，这是修正后的值。

完整更新记录：https://github.com/Llesue/filehub/compare/v0.2.7...v0.2.8
