# FileHub 0.2.3

0.2.3 is a stability patch for remote mounts and the text editor.

## Remote roots

- `GET /api/v1/roots` now returns `online` for every root. Local roots are always `true`.
- A remote root is `false` when the probe fails, times out, or its token or grant is no longer valid.
- Requests to an unreachable remote return `503 REMOTE_OFFLINE` instead of `500 INTERNAL_ERROR`.
- An HTTP 4xx from the peer keeps its own status; it is never reported as offline.
- The sidebar moves an offline remote root into the offline group and shows a readable notification when a request fails.

## Editor encodings

- Detection now covers UTF-16 with and without a BOM, GBK/GB18030, Big5, Shift-JIS, EUC-KR, Windows code pages and ISO-8859-1/15.
- Legacy encodings are scored by replacement characters, control characters and mixed-script heuristics instead of trusting a single guess.
- Binary files and control-heavy content are refused, so a save can no longer re-encode them by accident.
- `probe` now also returns `encoding`, `bom` and `lossy`; `reason` can be `text`, `lossy`, `binary`, `empty` or `too_large`.

## Upgrade

No database migrations. Existing data upgrades in place.

# FileHub 0.2.3

0.2.3 是一个针对远程挂载和文本编辑器的稳定性修复版本。

## 远程目录

- `GET /api/v1/roots` 现在为每个根返回 `online`，本地根始终是 `true`。
- 远程根探测失败、超时，或令牌/授权失效时返回 `false`。
- 访问不可达的远程根返回 `503 REMOTE_OFFLINE`，不再是 `500 INTERNAL_ERROR`。
- 对端返回的 HTTP 4xx 保持原状态码，不会被误判为离线。
- 侧栏会把离线的远程根移入离线分组；请求失败时给出可读提示。

## 编辑器编码

- 检测覆盖 UTF-16（含无 BOM）、GBK/GB18030、Big5、Shift-JIS、EUC-KR、Windows codepage 和 ISO-8859-1/15。
- 旧编码按替换字符、控制字符和混排脚本打分，不再只依赖单次猜测。
- 二进制文件和控制字符过多的内容会被拒绝，保存时不会误把它们整体重编码。
- `probe` 新增 `encoding`、`bom`、`lossy`；`reason` 取值为 `text`、`lossy`、`binary`、`empty` 或 `too_large`。

## 升级

没有数据库迁移，现有数据可直接升级。
