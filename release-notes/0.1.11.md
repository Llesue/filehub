
FileHub v0.1.11

A bigger release. Highlights:

## Sharing
- Copying a link no longer invalidates previously shared links
- Share dates use relative labels ("3 days ago", "in 5 hours")
- "Reset link" is now a separate action with confirmation
- Expired shares show as stopped; enabling one extends it by one day and shows the new date
- Expiry dropdown no longer silently reads "permanent"
- QR codes on the share list and after creating a share
- Stopped shares only show "Enable share" and "Delete"

## Editor
- Non-UTF-8 support: GBK, Big5, Shift_JIS, EUC-KR, UTF-16, Windows-1252
- Encoding picker; saves round-trip in the original encoding and keep the BOM
- Characters that cannot be encoded offer a UTF-8 fallback
- CodeMirror editor with syntax highlighting, languages lazy-loaded
- Markdown preview now styles tables, quotes, lists and images; code blocks are highlighted
- Large documents no longer re-render on every keystroke

## Mobile
- Visible "⋯" menu; bottom action sheet on phones
- Dialogs become bottom sheets and respect safe areas
- 16px inputs prevent iOS auto-zoom
- Swipe left/right in the image preview
- Installable as a PWA

## Other
- Closing the terminal disconnects and destroys the session; minimizing keeps it
- Terminal command history with ↑/↓
- Account menu anchored below the avatar on mobile
- The current directory polls for external changes every 5 seconds
- Online indicator in the admin user list
- Six previously inert system settings now work (symlinks, per-directory entry limit)

## Notes
- English translations are complete; CI now fails on missing keys
- Terminal history is per-user and cleared on logout
- Secure cookies cannot be enabled over plain HTTP
- Existing share links keep working
- Back up filehub.db before upgrading

FileHub v0.1.11

这次东西比较多，挑重点说。

## 分享
- 复制地址不会再让之前发出去的链接失效了，链接是固定的
- 分享日期改成「3 天前」「5 小时后」这种相对时间
- 需要换链接就点「重置链接」，会二次确认
- 过期分享显示成「已停止」，点「启用分享」自动续 1 天，并提示到哪天
- 过期下拉框不再莫名其妙变成「永久」
- 分享页和创建成功弹窗都能出二维码
- 停止分享后只保留「启用分享」和「删除」

## 编辑器
- 支持非 UTF-8：GBK、Big5、Shift_JIS、EUC-KR、UTF-16、Windows-1252
- 底部可以手动切换编码，保存按原编码写回并保留 BOM
- 存不下的字符会提示改用 UTF-8
- 换成 CodeMirror，代码有高亮了，语言按需加载
- Markdown 预览补齐表格、引用、列表、图片样式，代码块也有高亮
- 大文档不再每次按键都重新渲染

## 手机
- 文件列表有「⋯」菜单，手机上是底部操作表
- 弹窗在手机上是底部抽屉，适配刘海和 Home 条
- 输入框 16px，iOS 不会自动放大
- 图片预览支持左右滑动
- 可以添加到主屏当 PWA 用

## 其他
- 终端关闭会断开并销毁会话；最小化保留会话和滚动记录
- 终端支持 ↑/↓ 翻命令历史
- 手机端账号菜单固定到头像下方
- 外部改完文件，目录每 5 秒自动刷新
- 管理页用户列表显示在线状态
- 修了 6 个以前改了没用的系统设置（符号链接、索引条目上限等）

## 安全
- 登录按 IP 限流，Argon2 并发有上限
- 分享密码按分享 + IP 限流
- 编辑器拒绝已知二进制文件
- 终端历史按用户隔离，退出登录清理
- 非 HTTPS 下不能开启 Secure Cookie
- 修复停止分享卡片的文字对比度

## 说明
- 英文翻译补齐，CI 会检查缺 key
- 老分享链接继续有效
- 升级前建议备份 filehub.db
