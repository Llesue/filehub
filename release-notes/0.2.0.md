FileHub 0.2.0

Remote directory mounts between FileHub instances. A user can authorize a directory to another instance with a scoped token, read-only or read-write, and mount it as a remote root. Mounted directories support browsing, download, upload, create, rename, delete, copy, move, search, image and text preview, and packaging files as ZIP. Remote thumbnails, directory sizes and properties are proxied and cached locally. The sidebar now has a GitHub link and an optional update check. Admins can enable remote mounts and outgoing shares per user.

Demo: https://filehub.ihtom.com (demo / filehub2026)

FileHub 0.2.0

FileHub 实例之间的远程目录挂载。用户可以把自己的目录按只读或读写授权给另一个实例，对方挂载后可以浏览、下载、上传、新建、重命名、删除、复制、移动、搜索、预览图片和文本，以及把文件打包成 ZIP。缩略图、目录大小和属性都会走代理并在本地缓存。侧栏增加了 GitHub 入口和可选的更新检查。管理员可以按用户开启远程挂载与对外授权。

Demo：https://filehub.ihtom.com（demo / filehub2026）
