FileHub 0.2.0

Remote directory mounts between FileHub instances. A user can authorize a directory to another instance with a scoped token, read-only or read-write, and mount it as a remote root. Mounted directories support browsing, download, upload, create, rename, delete, copy, move, search, image and text preview, recursive ZIP downloads, in-place ZIP extraction, audio tracks and video preview. Remote thumbnails, directory sizes and properties are proxied and cached locally, and opening a remote directory warms its thumbnails. The sidebar now has a GitHub link and an optional update check. Admins can enable remote mounts and outgoing shares per user. Federation writes accept idempotency keys and uploads honor ETag preconditions.

Also in this release:

- Share QR codes generate reliably.
- Markdown files open in preview mode by default.
- Admin feature, role, quota and account changes apply to open sessions without a reload.
- One-time federation tokens are cleared when the sharing dialog closes.

Demo: https://filehub.ihtom.com (demo / filehub2026)

FileHub 0.2.0

FileHub 实例之间的远程目录挂载。用户可以把自己的目录按只读或读写授权给另一个实例，对方挂载后可以浏览、下载、上传、新建、重命名、删除、复制、移动、搜索、预览图片和文本，把目录递归打包成 ZIP、就地解压，以及选择音轨和预览视频。缩略图、目录大小和属性都会走代理并在本地缓存，打开远程目录时还会预热缩略图。侧栏增加了 GitHub 入口和可选的更新检查。管理员可以按用户开启远程挂载与对外授权。联邦写操作支持幂等键，上传支持 ETag 前置条件。

本次还包括：

- 分享二维码可以正常生成。
- Markdown 文件默认以预览模式打开。
- 管理员修改功能开关、角色、配额或账号状态后，已登录页面无需刷新即可生效。
- 关闭远程共享对话框后会清除一次性令牌。

Demo：https://filehub.ihtom.com（demo / filehub2026）
