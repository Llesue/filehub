# FileHub 0.2.7

0.2.7 fixes remote-directory paging, editor column alignment and an index database-lock race, and adds admin-managed avatars.

## Highlights

- Remote directories no longer repeat the first page when you scroll to load more.
- Full index scans no longer fail with `database is locked`.
- Text-file Tab now replaces a partial same-line selection, indents whole-line or multiline selections, and inserts a tab at the cursor.
- Chinese text in the editor now lines up exactly two Latin cells wide without changing the Latin mono font.
- The admin user list shows avatars, and admins can crop and replace any user's avatar.
- Per-user remote mount and sharing toggles hide immediately when their global feature is disabled.

## Upgrade

No database migrations. Existing 0.2.6 data upgrades in place.

Full changelog: https://github.com/Llesue/filehub/compare/v0.2.6...v0.2.7

Demo: https://filehub.ihtom.com (demo / filehub2026)

# FileHub 0.2.7

0.2.7 修复远程目录分页、编辑器列对齐和索引数据库锁竞态，并加入管理员头像管理。

## 亮点

- 远程目录滚动加载更多时不再重复第一页。
- 全量索引扫描不再因 `database is locked` 失败。
- 文本文件的 Tab 现在会替换同一行内的部分选区，整行或多行选区整体缩进，无选区时在光标处插入制表符。
- 编辑器中中文正好占两个英文字符宽，同时不改变英文字体。
- 系统管理用户列表显示头像，管理员可以裁剪并更换任意用户的头像。
- 系统管理关闭远程挂载或对外授权后，用户管理里的对应开关立即隐藏。

## 升级

没有数据库迁移，现有 0.2.6 数据可直接升级。

完整更新记录：https://github.com/Llesue/filehub/compare/v0.2.6...v0.2.7

Demo：https://filehub.ihtom.com （demo / filehub2026）
